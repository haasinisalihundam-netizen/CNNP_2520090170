# 🧪 CNNP | Skill-Based Experiments

## 📖 Overview

This directory is dedicated to the practical experiments conducted as part of the **Computer Networks and Network Programming (CNNP)** course.

The experiments explore the fundamental principles of computer networking through hands-on activities involving network protocols, packet analysis, socket programming, routing, performance evaluation, and network troubleshooting.

The objective is to bridge theoretical knowledge with practical implementation and develop a deeper understanding of how modern computer networks operate.

## 🎯 Objectives

- Understand network architecture, protocol layering, and encapsulation.
- Analyze network packets and protocol headers.
- Explore TCP/IP communication and socket programming.
- Study network addressing, routing, and switching.
- Evaluate network performance, latency, throughput, and congestion.
- Understand network security, traffic management, and troubleshooting.
- Gain practical experience with network analysis and configuration tools.

## 📚 Areas Covered

| Module | Focus Area |
|---|---|
| CO1 | Network Measurement, Encapsulation, and Performance Analysis |
| CO2 | Socket Programming, TCP/UDP, HTTP, DNS, and TLS |
| CO3 | IP Addressing, Subnetting, Routing, and Internetworking |
| CO4 | Ethernet, Switching, VLANs, and Wireless Networking |
| CO5 | Network Operations, Security, Troubleshooting, and Automation |
| CO6 | Quality of Service, Multicast, and Real-Time Networking |

## 🔬 Practical Approach

The skill-based experiments emphasize:

- **Observation:** Capturing and examining real network traffic.
- **Analysis:** Interpreting protocol behavior and network performance.
- **Implementation:** Applying networking concepts through practical configurations and programming.
- **Troubleshooting:** Identifying network issues and evaluating solutions.
- **Documentation:** Recording experimental procedures, observations, calculations, and results.

## 📂 Repository Contents

Individual experiment directories contain relevant practical work, which may include:

- Experiment objectives and procedures
- Network configurations and source code
- Packet analysis and observations
- Screenshots and experimental results
- Calculations and performance evaluations
- Experiment reports and documentation

## 🚀 Learning Outcomes

Through these experiments, the aim is to develop practical skills in understanding, implementing, analyzing, and troubleshooting computer networks, establishing a foundation for further exploration in networking, cybersecurity, distributed systems, and network engineering.
